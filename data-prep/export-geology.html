Export USGS geology to GeoJSON

Converts the geologic units of USGS map SIM 3464 (an ArcGIS geodatabase) into site/data/geology.geojson, in latitude and longitude. It uses GDAL compiled for the browser (gdal3.js), so nothing has to be installed.

  1. Put Nili.gdb from sim3464_database.zip into a zip named data-prep/work/Nili.gdb.zip (the zip must contain the Nili.gdb folder).
  2. Run prep-server.ps1 and open this page from it.
